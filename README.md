# Entspannt Reisen

Bahn-Lernplaner mit KI-Zusammenfasser und Echtzeit-DB-Sync (CustomTkinter-Desktop-App).

## Start

```
pip install -r requirements.txt
playwright install chromium
pythonw EntspanntReisen.pyw
```

Einstellungen (API-Keys, DB-Login, aktuelle Reise) werden lokal in `.entspannt_reisen.json` gespeichert und sind nicht im Repo enthalten.
